# NFS Most Wanted Rework Plus

**PT-BR:** melhorias para o *Need for Speed: Most Wanted* (2005) no PC, principalmente para o mod **Rework**:
vibração no controle, painel de opções no menu Home e correções (nitro que não recarrega, cutscenes puladas, rastro do nitro).

**EN:** improvements for *Need for Speed: Most Wanted* (2005) on PC, mainly for the **Rework** mod:
controller rumble, an options panel in the Home menu, and fixes (nitro not recharging, skipped cutscenes, missing nitro trail).

---

## Instalação (PT-BR)

1. Baixe o `.zip` em [**Releases**](../../releases) e extraia.
2. Feche o jogo e execute `instalar.exe`.
3. *(Opcional, só Rework)* Execute `ajustes_rework.exe` para aplicar as correções de nitro, cutscenes e rastro.
4. Abra o `mw_rumble.exe` e deixe aberto enquanto joga.
5. No jogo, aperte **Home** e abra a página **NFS_MW_Opcoes** para ligar/desligar cada opção.

Para desinstalar: `instalar.exe --desinstalar`.

## Install (English)

1. Download the `.zip` from [**Releases**](../../releases) and extract it.
2. Close the game and run `instalar.exe`.
3. *(Optional, Rework only)* Run `ajustes_rework.exe` to apply the nitro, cutscene and trail fixes.
4. Open `mw_rumble.exe` and keep it open while you play.
5. In game, press **Home** and open the **NFS_MW_Opcoes** page to toggle each option.

To uninstall: `instalar.exe --desinstalar`.

## Informações / Info

- **PT-BR:** controle Xbox funciona direto; PlayStation via [DS4Windows](https://github.com/Ryochan7/DS4Windows). O painel precisa do ReShade 4.9.1; sem ele a vibração funciona igual. Testado no Rework (Windows 11, DualSense). Só jogo offline. O instalador faz backup (`*.bak_vibracao`).
- **EN:** Xbox controllers work directly; PlayStation ones through [DS4Windows](https://github.com/Ryochan7/DS4Windows). The panel needs ReShade 4.9.1; rumble works without it. Tested on Rework (Windows 11, DualSense). Offline play only. The installer makes backups (`*.bak_vibracao`).
